## Title

LinkedIn Publisher: post to LinkedIn safely from your agent

## Short description (one line)

Write, preview and publish every kind of LinkedIn post from Claude, Cursor or any MCP agent, using LinkedIn's official API. Nothing goes live without your yes.

## Long description

Turn your agent into a careful LinkedIn assistant. This skill pairs with **linkedin-mcp**, a free, open-source (MIT) MCP server, and teaches your agent how to use all 21 of its tools well:

- **Every self-serve post type:** text, link cards, single images, 2–20 image galleries, MP4 videos, PDF/slide carousels, polls and reshares, plus editing and deleting your own posts.
- **A strict confirm-first workflow:** the agent writes the post, shows you a `preview_post` of exactly what will be sent, and only publishes after you say yes. Edits, reshares and deletes get the same treatment.
- **Guided setup:** step-by-step help creating your own LinkedIn developer app, signing in, and connecting the server to Claude Code, Claude Desktop, Cursor or any stdio MCP client.
- **Local drafts:** save, refine and publish posts later.
- **Your full profile from LinkedIn's data export**, read locally (headline, experience, education, skills and more), for posts and resumes that sound like you.
- **Job search:** filtered LinkedIn Jobs links, plus real listings from Greenhouse, Lever, Ashby and Remotive.
- **Know-how built in:** LinkedIn's limits, mention syntax, link-card titles, token expiry, API-version and rate-limit errors, and an honest list of what LinkedIn's API doesn't allow, so the agent never promises something it can't do.

**Privacy:** you bring your own LinkedIn app. Your token stays on your machine in `~/.config/linkedin-mcp/`, and nothing is scraped.

**What you're paying for:** the server code is free on GitHub (github.com/amankumar-2001/linkedin-mcp). This skill is the agent playbook: setup guidance, a safe posting workflow, and tool-by-tool know-how.

**Requirements:** Node.js 20+, a LinkedIn account, and a LinkedIn Company Page you admin (LinkedIn requires one to create a developer app; you can create one for yourself).
